# 🌈 Prismatica

> A colorful calculator that turns boring math into a light show.

**Prismatica** — это яркий калькулятор на Python + Tkinter: три режима работы, семь цветовых тем, два языка и поддержка полноэкранного режима. Без сторонних библиотек — только стандартная библиотека Python.

---

## ✨ Возможности

### 🎨 7 цветовых тем
- 🌈 Rainbow
- 💜 Neon
- 🌅 Sunset
- 🌊 Ocean
- 🌲 Forest
- 🚀 Space
- 🌸 Pastel

Переключаются на лету — весь интерфейс мгновенно перекрашивается.

### 🧮 3 режима работы

| Режим | Что умеет |
|---|---|
| **Basic** | `+ − × ÷`, проценты, смена знака |
| **Scientific** | `sin/cos/tan` (в градусах), `ln`, `log`, `√`, `x²`, `xʸ`, `n!`, `1/x`, `π`, `e`, скобки |
| **Programmer** | HEX/DEC/OCT/BIN, побитовые `AND OR XOR NOT`, сдвиги `<< >>`, вывод во всех 4 системах сразу |

### 🌐 Два языка
- 🇷🇺 Русский
- 🇬🇧 English

Переключение мгновенное, прямо во время работы.

### ✨ Приятные мелочи
- **Hover-подсветка** — кнопка светлеет при наведении
- **Эффект нажатия** — кнопка темнеет при клике
- **Авто-контраст текста** — цвет цифр сам подбирается под фон кнопки
- **Свечение дисплея** под цвет акцентной темы
- **F11** — полный экран, **Esc** — выход
- **Ввод с клавиатуры** — цифры, `+ − * / ( ) % ^`, Enter, Backspace, Delete
- **Автозакрытие скобок** — `sin(30` посчитается как `sin(30)`
- **Неявное умножение** — `2π` понимается как `2*π`

## 🚀 Запуск

### Требования
- **Python 3.8+**
- **tkinter** — входит в стандартную библиотеку на Windows и macOS.
  На Linux (Ubuntu/Debian) может потребоваться:
  ```bash
  sudo apt install python3-tk
  ```

### Установка

```bash
git clone https://github.com/ТВОЙ_НИК/prismatica.git
cd prismatica
python prismatica.py
```

Никаких `pip install` — только стандартная библиотека. 🎉

## ⌨️ Горячие клавиши

| Клавиша | Действие |
|---|---|
| `0–9`, `.` | Ввод цифр |
| `+ − * /` | Операции |
| `( )` | Скобки |
| `%` | Процент |
| `^` | Степень |
| `Enter` | Посчитать |

| `Delete` | Очистить всё |

| `Esc` | Выйти из полного экрана |
